## 🛠️ Getting Started

### Prerequisites

- Node.js ^16.14.0 || ^18.10.0
- Yarn

### Clone the Repository

```bash
git clone https://github.com/jtg-inductions-fe/FE-Assignment-2-Kritman-Kumar-UID00727-2026.git
cd restaurant-admin-dashboard
```

### Install Dependencies

```bash
yarn install
```

### Start the Development Server

```bash
yarn start
```

Open your browser and navigate to:

```
http://localhost:4200
```

### Run ESLint

```bash
yarn lint
```

### Build the Project

```bash
yarn build
```

## 📐 Development Standards

- Follow the **Angular Style Guide**.
- Follow the **BEM** naming convention.
- Build reusable and modular components.
- Use SCSS Design Tokens for colors, typography, spacing, border radius, shadows, and breakpoints.
- Follow the **Mobile-First** responsive approach.
- Keep business logic out of templates.
- Use TypeScript path aliases instead of long relative imports.
- Keep components small and focused on a single responsibility.
